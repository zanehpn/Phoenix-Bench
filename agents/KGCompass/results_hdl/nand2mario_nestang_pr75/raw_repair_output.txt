The issue is about the NES/SNES controller connector pinout. The relevant pin mapping is already documented in `src/controller_snes.v`, and the top-level wiring for `CONTROLLER_SNES` is in `src/nestang_top.sv`.

For an NES controller, you can use the same SNES-style 7-pin connector mapping shown in the comment:

- Pin 1: +5V
- Pin 2: Data clock
- Pin 3: Data latch / strobe
- Pin 4: Serial data
- Pin 7: Ground

Pins 5 and 6 are not used.

No code change is needed for the pinout itself, but if you want to make this clearer for users, the most useful fix is to add an explicit NES controller pinout note in the controller module comment.
