The bug is localized in `hw/system/occamy/src/occamy_xilinx.sv`:

- It includes `axi_flat.svh`
- But the repository only contains `axi_flat.sv`
- That means Vivado fails to find the header, and the macro `AXI_FLATTEN_MASTER` remains undefined

The fix is to update the include to point to the existing file.

```systemverilog
### hw/system/occamy/src/occamy_xilinx.sv
<<<<<<< SEARCH
`include "axi_flat.svh"
=======
`include "axi_flat.sv"
>>>>>>> REPLACE
```
